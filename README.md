# Supreme Fitness Gym App

A group project developed as part of Software Engineering studies to support gym management and fitness-related activities.

## Project Structure

- `frontend/` — Frontend web application
- `backend/` — Backend web service and API

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- React Router
- Material UI (MUI)
- Axios
- Chart.js
- Stripe.js and React Stripe.js

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- bcryptjs
- Nodemailer
- Stripe

### Development Tools
- ESLint
- Nodemon
- Tailwind CSS and related build tools

## Main Features

The application is designed for gym-related management and fitness services. Specific features will be documented after reviewing the implemented functionality.
